## 💰 Multi-Agent Finance Intelligence System

A sophisticated multi-agent system for personal finance management built using AI agent principles.

### 🚀 Quick Start

```bash
# Run with example data
python3 cli.py example_input.json

# Run with custom budget
python3 cli.py example_input.json 50000

# Run tests
python3 test_system.py
```

### 🎯 Features

- **Category Agent**: Automatically categorizes transactions into 10+ spending categories
- **Budget Agent**: Analyzes spending patterns and predicts end-of-month totals
- **Advisor Agent**: Provides personalized financial advice and investment suggestions
- **Zero Dependencies**: Uses only Python standard library
- **JSON API**: Easy integration with other systems
